# 3d-vector-calculator — agent conventions

This app was generated by Sample App Studio. Keep these conventions when changing it.

## Stack (fixed)
Node.js 22 with zero npm dependencies: a node:http static server (server.mjs), vanilla ES modules in public/, localStorage for persistence, and node:test tests.
- package.json: "type": "module", scripts {"start": "node server.mjs", "test": "node --test"}; no dependencies.
- server.mjs serves public/ over plain HTTP on loopback (process.env.PORT, default 4100) with correct content types and never serves files outside public/. Do not add TLS certificates or keys, or an Agent SDK companion.
- Pure logic lives in public/lib/*.js (importable from node:test); DOM code lives in public/app.js.
- Tests live in test/*.test.mjs and import from ../public/lib/.
- README.md explains what the app does and how to run and test it.
